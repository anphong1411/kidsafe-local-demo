# KidSafe LAN server

Python 3.11+, FastAPI, SQLAlchemy and SQLite WAL. Run from the repository root using the root locked dependencies and launcher documented in `README.md`. The server itself never configures DNS, Windows trust stores or services.

Configuration is required before import of `server.main`: `KIDSAFE_DATABASE_URL`, `KIDSAFE_ENCRYPTION_KEY` (base64 32 bytes), `KIDSAFE_SIGNING_SEED` (base64 32 bytes), and `KIDSAFE_ALLOWED_HOSTS` (comma-separated DNS names/IPs used in the TLS certificate). Keys must stay in the ignored, ACL-restricted lab configuration. Back up the database and keys together; losing the AES key makes encrypted names/audit unreadable. Changing it is not key rotation.

Use the provided launcher for TLS 1.2+ with the generated lab certificate. Uvicorn runs one worker: WebSocket routing and IP rate counters are process-local. Do not expose this LAN project to the public Internet without reviewing deployment, proxy trust, limits and durable connection routing.

The additive, idempotent schema migration runs when `create_app` initializes. `schema_versions` records versions 1 and 2; early lab allocation/status columns are added without deleting data. Event table has seven explicit columns and an implicit SQLite rowid, with idempotency in a separate batch table. Startup upgrades early plaintext audit IP/old/new and consent IP to AES-GCM and rejects an unusable encryption key.

Parents can register at `/register` with a display name, username and password (minimum 10 characters), then sign in at `/login`. Public registration always creates a parent; it cannot set admin or child-view roles. It requires a same-origin pre-auth CSRF cookie/header and has a separate 10-request/minute/IP limit. Names are AES-GCM encrypted; passwords use scrypt. The administrator can still provision accounts using `python -m server.seed --username parent@kidsafe.local --config <path/to/lab.json>`; omit `--password` to enter it securely. Parents create child profiles, grant consent and generate enrollment codes through the dashboard/API. Children use the paired native Windows app without web credentials; child-view web accounts remain available only for legacy compatibility. SQL ownership filters apply to all child data. See [account persistence and deployment](../docs/ACCOUNT_SETUP.md).

See [API contract](../docs/API_CONTRACT.md) for payloads and guarantees. The initial editable quota is 120 minutes on weekdays/weekends; this is an implementation seed, not a quota chosen by the user. Configure a child's quota before first enrollment where possible. The first device receives unreserved quota, later devices start at zero. Offline rights are never reclaimed on timeout or revocation. Returning/transferring recurring shares requires a durable donor acknowledgment and takes effect the next day, preserving today's reserved rights. Shared quota reductions are blocked while those rights remain outstanding. One child-wide unlock exception can be active at a time; a new one requires expiry or acknowledgment that the prior target was locked.

Run `python -m pytest tests/server -q --basetemp=.tmp/pytest-server`. On this Windows sandbox, FastAPI TestClient's asyncio loopback sockets require approved execution outside the sandbox; the suite uses temporary databases. Tests cover real API state changes, cross-family access, cryptography tampering, session/CSRF, enrollment replay, token rotation, seven-field event validation and duplicate multiplicity, ordered/idempotent commands, child-wide exceptions, durable budget ACKs, child requests, retention and offline deletion status. TLS transport and Windows/DNS lab checks are covered separately and are not claimed by these unit/API tests.

Build a source bundle with `python scripts/package_release.py`; default output is `.tmp/releases/KidSafe-source.zip` with `MANIFEST.sha256.json` inside. Dependencies/private runtime are excluded; install from the included dependency files on the target. The host-dependent `scripts/browser_check.mjs` developer QA helper is deliberately excluded from the release.
